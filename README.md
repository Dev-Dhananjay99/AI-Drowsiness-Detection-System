# AI Drowsiness Detection System

An AI-based real-time drowsiness and yawning detection system developed using Python and Computer Vision.

## Features

- Real-time drowsiness detection
- Yawning detection
- Facial landmark tracking
- Eye Aspect Ratio (EAR) analysis
- Mouth Aspect Ratio (MAR) analysis
- Real-time alert generation
- Live webcam monitoring
- Laptop webcam support
- DroidCam support
- Portrait and landscape camera support
- Camera selection
- User-friendly graphical interface

## Technologies Used

- Python
- OpenCV
- MediaPipe
- Tkinter
- SciPy
- Pillow
- Pygame

## How It Works

Camera Input  
↓  
Face Detection  
↓  
Facial Landmark Detection  
↓  
EAR & MAR Calculation  
↓  
Drowsiness / Yawning Detection  
↓  
Alert Generation  
↓  
GUI Status Display
